# Design

I want the project to look like a modern English school dashboard.

Main colors:
- dark burgundy for buttons and important parts
- warm yellow for small accents
- soft light background
- dark sidebar

Text should be readable. Most UI text uses Montserrat. Big title text can use SinaNova.

Cards, buttons and inputs should be simple, with 8px radius. No heavy shadows, no overloaded colors.
